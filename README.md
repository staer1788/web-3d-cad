# Web 3D CAD

**Live Demo:** [https://staer1788.github.io/web-3d-cad/](https://staer1788.github.io/web-3d-cad/)

A simple, browser-based 3D CAD application that runs entirely on the client-side. This application is designed to be hosted on static web platforms like GitHub Pages.

---

シンプルな、ブラウザベースの3D CADアプリケーションです。完全にクライアントサイドで動作し、GitHub Pagesのような静的ウェブホスティングサービスで動作するように設計されています。

## Features / 機能

- **Language Selection / 言語選択**: Choose between English and Japanese. / 英語と日本語を選択可能。
- **Project Management / プロジェクト管理**:
  - Create new projects. / 新規プロジェクトの作成。
  - Save projects to the browser's LocalStorage. / プロジェクトをブラウザのLocalStorageに保存。
  - View a list of all saved projects. / 保存された全プロジェクトの一覧表示。
- **File I/O / ファイル入出力**:
  - Export projects as a `.json` file. / プロジェクトを`.json`ファイルとしてエクスポート。
  - Import projects from a `.json` file. / `.json`ファイルからプロジェクトをインポート。
- **3D Editor / 3Dエディタ**:
  - A basic 3D viewer powered by Three.js. / Three.jsによる基本的な3Dビューア。
  - Navigate the scene using orbit controls (drag to rotate, scroll to zoom, right-drag to pan). / オービットコントロールによるシーン操作（ドラッグで回転、スクロールでズーム、右ドラッグでパン）。

## How to Use / 使い方

Simply open the `index.html` file in a modern web browser that supports ES Modules and LocalStorage (e.g., Chrome, Firefox, Safari, Edge).

---

ESモジュールとLocalStorageをサポートするモダンなウェブブラウザ（Chrome, Firefox, Safari, Edgeなど）で`index.html`ファイルを開くだけです。
